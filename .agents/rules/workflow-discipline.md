# Kamihi Remote Engineering Discipline & Thinking Protocol

## Core Rules
1. **Never equate "Build Succeeded" with "Feature Works"**: Gestures, scroll physics, networking, pairing, encryption, Bluetooth, and controller input all require runtime execution verification with evidence before any task is declared complete.
2. **Commands & Shortcuts**:
   - `/ultra`, `/max`, `/xhigh` triggers the **5-Stage Ultra Deliberation Framework** (First-Principles State Space Mapping, Adversarial Pre-Mortem, Multi-Path Trade-Offs, Formal TDD Contract, and Evidence-Backed Completion).
   - Superpowers skills (`brainstorming`, `writing-plans`, `systematic-debugging`, `test-driven-development`, `verification-before-completion`) must always govern non-trivial code modifications.
3. **Evidence Before Assertions**: Always execute verification commands and inspect actual outputs/logs before reporting results to the user.
