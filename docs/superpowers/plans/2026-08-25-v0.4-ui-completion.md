# Kamihi Remote v0.4 UI Completion Plan

## First principles
- One remote surface, not five mini-apps.
- Primary nav: Trackpad | Present | Deck | Controller (≤4).
- Keyboard + Settings = floating utilities, not tabs.
- Touch dots: exact UITouch points, stable Finger ID, 1–4 visible.
- Controller: portrait = rotate prompt only; landscape = immersive pad.
- Deck: one-tap Mac app gallery, not nested editors.

## Trade-off (touch visuals)
| | SwiftUI overlay (A) | UIKit CALayer dots (B) |
|---|---|---|
| Exact coords | Needs size sync | Native |
| Liquid Glass | Native | Hard |
| Latency | Low if no spring on position | Lowest |
**Choice:** A with overlay bound to UIKit trackpad + `preciseLocation` + no position animation (already started). Strengthen spring-in/out only.

## Verification contract
- `xcodebuild` iOS + macOS succeed
- GestureEngineTests self-checks pass at launch
- Simulator: portrait + landscape smoke (simctl)
- Physical: UNVERIFIED unless device available
- Security review before push claim
